# ICP y User Persona — Taller Mecánico Don Ramiro

## Perfil del taller

Taller mecánico pequeño de **4 mecánicos**, con atención de autos particulares y trabajo de piso. No tienen software de gestión caro; operan con celular o, sobre todo, con **una tablet compartida** en el área de trabajo.

**Contexto de uso**
- Turnos con varios vehículos en paralelo
- Poco tiempo para mirar la pantalla
- Manos sucias / uso táctil rápido
- Necesidad de saber **en qué estado está cada auto** y **quién lo está trabajando**
- Problemas frecuentes: llamadas de clientes preguntando por el auto, y discusiones por trabajos extra no registrados con claridad

**Qué valoran**
- Ver el estado en segundos (semáforo)
- Saber qué autos tiene cada mecánico
- Pocos toques, botones grandes
- No depender de un sistema en la nube ni de cuentas complicadas

**Qué no es prioritario para ellos**
- Reportes contables complejos
- App nativa de tienda
- Multi-sucursal

## User persona principal

### Ramiro — Mecánico de piso / referente operativo

| Campo | Detalle |
|--------|--------|
| **Rol** | Mecánico; en la práctica ordena el ingreso y la asignación de trabajos |
| **Edad** | ~40 años |
| **Entorno** | Taller de 4 personas; usa la **tablet compartida** entre un auto y otro |
| **Objetivo** | Que cada auto tenga responsable claro y que el estado (reparando / cotizando / listo) se entienda sin explicaciones largas |
| **Frustraciones** | “¿Este auto lo lleva Carlos o Luis?”; llamadas que interrumpen; extras que después el cliente discute |
| **Comportamiento** | Abre la app, ingresa el vehículo, **asigna mecánico al cargar**, mira el semáforo y sigue trabajando |
| **Frase típica** | “Si no tiene nombre, no sé de quién es. Que salga asignado desde que entra.” |

### El equipo (4 mecánicos)

1. **Ramiro** — referente; suele cargar ingresos y asignar  
2. **Carlos** — mecánico de piso  
3. **Ana** — mecánica de piso  
4. **Luis** — mecánico de piso  

Todos comparten la misma tablet y la misma vista. La app debe permitir **ver de un vistazo cuántos autos tiene cada uno** y **cambiar la asignación** si hace falta (por ejemplo si Ramiro reasigna un trabajo).
